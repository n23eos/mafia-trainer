Документы и источники правил мафии

У мафии нет одного документа для всех клубов, турниров и домашних столов. Перед игрой выберите систему, найдите редакцию на сайте издателя и отдельно запишите изменения организатора. Эта страница помогает выбрать источник, но не объявляет любой каталог актуальным.

Сначала назовите систему правил

Фраза «играем по спортивным правилам» недостаточно точна. Попросите ссылку, издателя, дату редакции и список локальных изменений. Если турнир публикует собственный регламент, он может уточнять расписание, дисциплину и спорные процедуры поверх основного документа.

Сохраните ссылку до начала игры. Скриншот отдельного пункта полезен как быстрый ориентир, но без названия и редакции он теряет контекст.

MediaGame
Каталог документов MediaGame. Страница содержит ссылки на правила и регламенты. Полные тексты связанных файлов для этой статьи не прочитаны, поэтому их редакция и актуальность здесь не подтверждаются.
ФИИМ
Каталог правил ФИИМ. В нем представлены ссылки на правила, разъяснения и материалы для судей. Содержание связанных документов для этой статьи не прочитано, а их актуальность не обещается.

Наличие ссылки в каталоге не означает, что документ подходит вашей игре. Откройте сам файл и сопоставьте его с объявлением организатора.

Пять проверок перед использованием

  1. Совпадает ли издатель с системой, которую назвал ведущий?
  2. Есть ли на документе дата, номер версии или история изменений?
  3. Ведет ли ссылка на полный текст, а не на пересказ или старый снимок?
  4. Опубликованы ли отдельные разъяснения, которые дополняют документ?
  5. Перечислил ли организатор локальные изменения и приоритет документов при конфликте?

Если ответ неизвестен, так и запишите. Пометка «редакция не подтверждена» полезнее уверенного, но неподтвержденного заявления об актуальности.

Как использовать собственную памятку

Памятка ведущего может сокращать выбранный регламент для работы за столом: порядок команд, места для голосов, таймеры и контрольный список ночи. Подпишите ее как собственный материал и оставьте ссылку на первоисточник.

Не добавляйте домашнее правило в памятку ФСМ или ФИИМ без отдельной маркировки. Например, иной набор ролей можно использовать на домашнем столе, но нельзя выдавать его за состав конкретной федерации.

Для начала чтения откройте краткое введение в спортивную мафию. Организатору подойдет собственный чек-лист ведущего Mafia-tool.com.

Mafia rules documents and sources

There is no single Mafia document for every club, tournament, and home table. Before a game, choose a system, find an edition on the publisher's website, and record the organizer's changes separately. This page helps you select a source but does not declare every listed document current.

Name the rules system first

Saying "we use sport rules" is not precise enough. Ask for a link, publisher, edition date, and list of local changes. A tournament may publish its own regulations for scheduling, discipline, and disputed procedures in addition to the main rules document.

Save the link before the game begins. A screenshot of one section can be a quick reference, but without its title and edition it loses context.

Primary source directory

FSM
FSM rules PDF. This file was read for the library and is marked as the edition dated October 17, 2022. The website uses only short basic details about table composition and voting from it.
MediaGame
MediaGame document directory. The page links to rules and tournament regulations. The linked files were not read in full for this article, so their editions and current status are not confirmed here.
FIIM
FIIM rules directory. It lists rules, clarifications, and materials for officials. The linked documents were not read for this article, and their current status is not guaranteed.

A link in a directory does not mean the document fits your game. Open the file itself and compare it with the organizer's announcement.

Five checks before use

  1. Does the publisher match the system named by the host?
  2. Does the document show a date, version number, or change history?
  3. Does the link open the full text rather than a summary or old snapshot?
  4. Are there separate clarifications that supplement the document?
  5. Has the organizer listed local changes and document priority in case of conflict?

If the answer is unknown, record it as unknown. "Edition not confirmed" is more useful than a confident but unsupported claim that a document is current.

How to use your own reference sheet

A host reference sheet can condense the selected ruleset for table use: command order, spaces for votes, timers, and a night checklist. Label it as your own material and keep a link to the primary source.

Do not add a home rule to an FSM or FIIM reference sheet without a separate label. A different role set may work at a home table, but it should not be presented as a federation's composition.
